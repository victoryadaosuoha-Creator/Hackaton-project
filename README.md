# Déglu Gambia

Frontend-only civic reporting prototype for The Gambia.

**Your voice. Our community. A better Gambia.**

This is a demonstration interface. Figures, reports, institutions, and maps use local demo data. They are not official government statistics or live case records.

## Stack

React, TypeScript, Vite, Tailwind CSS, React Router, Lucide, Recharts, Leaflet.

## Scripts

```bash
npm install
npm run dev
npm run build
```
